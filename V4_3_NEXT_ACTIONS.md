# V4.3 — Prochaines actions

## Pour mettre réellement KÔKÔ en ligne

1. Choisir le fournisseur VPS.
2. Créer le serveur.
3. Installer Docker.
4. Configurer le pare-feu.
5. Configurer le domaine.
6. Déployer l'API.
7. Déployer PostgreSQL.
8. Configurer le stockage privé.
9. Activer HTTPS.
10. Tester `/api/health`.
11. Tester inscription/connexion.
12. Tester le parcours demande → devis → contrat.
13. Tester sauvegarde/restauration.
14. Garder les paiements en mode test jusqu'à validation PSP.
15. Préparer le pilote fermé.

## Information nécessaire pour l'étape suivante

Le déploiement réel nécessitera les accès que le propriétaire du compte doit fournir lui-même :
- compte VPS choisi ;
- domaine/sous-domaine ;
- accès serveur ;
- éventuellement compte de stockage ;
- plus tard compte marchand du PSP.

Ne jamais envoyer de mot de passe ou clé secrète dans le chat.
