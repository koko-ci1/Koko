# KÔKÔ — Budget infrastructure pilote

## Ordre de grandeur

Le serveur peut commencer dans une petite gamme de VPS, puis augmenter selon l'usage.

Budget mensuel à prévoir dans le modèle financier :
1. VPS
2. sauvegardes
3. stockage privé
4. nom de domaine/DNS si applicable
5. e-mails transactionnels
6. SMS/OTP
7. WhatsApp ou notifications selon fournisseur
8. paiement : frais du PSP
9. monitoring éventuel

## Important

Le coût serveur n'est qu'une partie du coût de KÔKÔ.

Pour un pilote, il faut surtout surveiller :
**coût par demande → coût par transaction → revenu par transaction.**

## Discipline financière

Ne pas acheter plusieurs serveurs avant d'avoir :
- des utilisateurs ;
- des transactions ;
- des métriques ;
- des problèmes de capacité mesurables.
